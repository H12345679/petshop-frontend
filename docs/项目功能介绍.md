# 宠物商城前端项目功能介绍

> **项目名称**: petshop-frontend  
> **技术栈**: Vue 2.6 + Vue Router 3 + Vuex 3 + Element UI 2 + Axios  
> **构建工具**: Vue CLI 5 (Webpack)  
> **开发端口**: 8099  
> **后端代理**: `http://localhost:8088`

---

## 一、项目概述

宠物商城是一个面向 C 端用户的宠物电商平台，同时提供商家/管理员后台管理功能。前端目前包含 **17 个页面**，覆盖用户端浏览购物、门店查询、视频内容以及后台数据管理四个主要场景。

---

## 三、路由与页面总览

### 3.1 前台页面（11 个）

| 路由 | 页面 | 说明 |
|------|------|------|
| `/` | `HomeView.vue` | 首页 — 分类导航、Banner、商品分区 |
| `/products` | `ProductsView.vue` | 商品列表/搜索 — 分类树、排序筛选 |
| `/product/:id` | `ProductDetailView.vue` | 商品详情 — SKU、购物车、收藏 |
| `/shops` | `ShopsView.vue` | 门店列表 — 搜索、卡片展示 |
| `/shop/:id` | `ShopDetailView.vue` | 门店详情 — 店内商品浏览 |
| `/videos` | `VideoListView.vue` | 视频列表 — 分类、分页 |
| `/video/:id` | `VideoDetailView.vue` | 视频详情 — 播放器、推荐 |
| `/login` | `LoginView.vue` | 登录页 |
| `/register` | `RegisterView.vue` | 注册页 |

### 3.2 后台页面（4 个）

| 路由 | 页面 | 说明 |
|------|------|------|
| `/admin` | `AdminLayout.vue` | 后台布局容器（侧栏 + 顶栏） |
| `/admin/shops` | `AdminShopsView.vue` | 门店管理 — 增删改查 |
| `/admin/products` | `AdminProductsView.vue` | 商品管理 — 增删改查、SKU |
| `/admin/videos` | `AdminVideosView.vue` | 视频管理 — 增删改查 |

### 3.3 路由守卫

- **后台路由** (`/admin/*`) 需登录且角色为 `ADMIN` 或 `MERCHANT`
- 已登录用户访问登录/注册页自动跳回首页
- 未登录访问需授权页面跳转到 `/login?redirect=原路径`

## 四、全局组件

### 4.1 AppHeader — 全局顶栏

- 毛玻璃导航栏（`backdrop-filter: blur`）
- 导航链接：首页、全部商品、找门店、萌宠视频
- 药丸形搜索框（输入关键词 → `/products?name=xxx`）
- 登录态显示用户昵称；管理员/商家显示"管理后台"入口
- 退出登录（清除 token 和 userInfo）

### 4.2 AppFooter — 全局页脚

- 深色背景，版权信息 `(c) 2026 宠物商城`

### 4.3 MapPicker — 腾讯地图选点弹窗

- 全屏遮罩 + 内嵌腾讯地图位置选择 iframe
- 通过 `postMessage` 监听选址，返回 `{ lat, lng, address, city }`
- 使用 `.sync` 修饰符控制显示/隐藏

## 五、页面功能详情

### 5.1 首页 (`/`)

- **左侧分类卡片**：从 API 获取分类树，点击跳转到 `/products?categoryId=xxx`
- **中央渐变 Banner**：纯 CSS 渐变 + 动画效果
- **右侧用户卡片**：已登录显示余额，未登录引导登录
- **商品分区**：热销榜单 (HOT)、新鲜上架 (NEW)、为你推荐 (RECOMMEND)
- 商品卡片显示：主图、名称、价格、原价（划线）、销量
- **AI 客服悬浮按钮**：底部固定，呼吸动画（仅 UI，未接入后端）

### 5.2 商品列表/搜索 (`/products`)

- **左侧分类树**：两级展开；API 失败时使用内置 mock 数据降级
- **筛选条件**：类型（宠物/周边）、排序（综合/销量/价格升/价格降/最新）、价格区间
- **面包屑导航**
- 商品 5 列网格展示 + ElementUI 分页
- URL 参数同步（`categoryId`、`name`、`type`）

### 5.3 商品详情 (`/product/:id`)

- 左侧图片区：主图 + 缩略图列表
- 右侧信息区：名称、描述、会员折扣价（根据 memberLevelId 计算）、规格 SKU 选择、数量增减
- 操作按钮：加入购物车、立即购买（占位）、收藏
- 详情 Tab 切换：商品详情 / 用户评价（空）/ 售后保障
- 侧栏"本店其他"商品推荐

### 5.4 门店列表 (`/shops`)

- 搜索筛选：关键词、营业状态
- 4 列网格卡片：LOGO、名称、地址、电话
- 分页
- "切换地图模式"按钮（`/map` 路由，**页面尚未实现**）

### 5.5 门店详情 (`/shop/:id`)

- 店招头部：LOGO、名称、营业状态、地址、电话
- 分类 Tabs：全部商品 / 宠物活体 / 周边用品 / 店铺简介
- 店内商品搜索 + 5列网格 + 分页

### 5.6 视频列表 (`/videos`)

- 分类 Tabs（推荐/全部 + 各分类），支持搜索
- ElementUI 骨架屏加载动画
- 视频网格卡片 + 分页
- 错误状态"重新加载"按钮

### 5.7 视频详情 (`/video/:id`)

- 左侧 HTML5 `<video>` 播放器
- 视频信息卡 + 同款商品推荐卡
- 右侧相关推荐列表（取前 6 条，排除当前视频）

### 5.8 登录页 (`/login`)

- 左右分栏布局：左侧蓝底品牌宣传区，右侧登录表单
- 表单校验非空
- 显示/隐藏密码、记住我（仅 UI）
- 第三方登录入口（微信/QQ，仅占位）
- 登录成功自动跳回 `redirect` 参数地址

### 5.9 注册页 (`/register`)

- 字段：用户名（4-16位）、密码（≥6位）、确认密码、昵称、手机号、邮箱
- 前端校验：密码一致性、手机号正则、邮箱正则
- 注册成功后跳转到登录页

### 5.10 后台管理 (`/admin`)

#### 布局 (`AdminLayout.vue`)

- 左侧深色侧栏，菜单分组：数据、商品、交易、运营
- 顶部信息栏：当前页面标题 + 用户名称

#### 门店管理 (`/admin/shops`)

- 表格展示：LOGO、名称、地区、电话、状态、创建时间
- 操作：编辑 / 切换营业状态 / 删除
- 新增/编辑弹窗：名称、电话、省市区、地址、经纬度（MapPicker 选点）、LOGO 上传、简介
- 状态切换和删除均有确认弹窗

#### 商品管理 (`/admin/products`)

- 搜索筛选：商品名、门店下拉、分类下拉（optgroup）、类型下拉
- 表格展示：缩略图、名称、分类、价格、库存、销量、上下架状态
- 操作：编辑 / 切换上下架 / 删除
- 新增/编辑弹窗：店铺/分类/类型选择、名称、价格、库存、主图上传（多张）、描述
- 当 type=2（周边商品）时显示 SKU 规格表格
- 根据角色自动过滤：MERCHANT 只能管理自己的商品

#### 视频管理 (`/admin/videos`)

- 搜索：标题模糊搜索
- 表格展示：封面、标题、关联商品、播放量、门店、发布时间
- 操作：编辑 / 预览（新窗口打开）/ 删除
- 新增/编辑弹窗：视频文件上传、封面图上传、标题、关联商品、门店、简介、上下架状态

## 六、API 概览

所有 API 通过 Axios 实例发送，基础路径 `/api`，自动携带 JWT Token（`Authorization: Bearer <token>`）。

| 模块 | 接口数 | 涵盖功能 |
|------|--------|----------|
| auth | 2 | 登录、注册 |
| home | 2 | 首页商品策略查询、分类树 |
| product | 9 | 商品 CRUD、搜索、购物车、收藏、图片上传 |
| shop | 5 | 门店 CRUD |
| video | 6 | 视频 CRUD、视频文件上传 |

> **注意**：地图 LBS 相关 API（`/api/map/*`）后端已实现，但前端尚未对接。

## 七、当前局限性

1. **Vue 2 技术栈**：按分工文档要求应升级至 Vue 3 + Vite + Pinia，目前仍为 Vue 2 + Vue CLI + Vuex
2. **Vuex 空壳**：全局状态管理未实际使用，所有跨组件状态依赖 localStorage
3. **地图页面缺失**：`/map` 路由引用的页面未实现（后端已就绪）
4. **AI 客服未接入**：首页悬浮按钮仅为占位
5. **部分功能仅 UI 占位**：立即购买流程、用户评价、第三方登录等
6. **无 TypeScript**：全部为 JavaScript
7. **Mock 降级覆盖不全**：仅商品列表页有 mock fallback，其他页面无降级方案
